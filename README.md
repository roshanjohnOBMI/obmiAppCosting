# OBMI time-saved explorer

React + Vite page that explores the OBMI tools time-saved estimates (80 functions across the Revit, Navisworks and web apps) with slicers, donut and range charts, a what-if table and CSV export.

- Data: `src/data.json` (exported from `OBMI Tools - Time Saved Estimate.xlsx`, `Data` sheet)
- Run: `npm install`, `npm run dev`
- Build: `npm run build` produces a single `dist/index.html` that also opens from disk

Planning estimates, not measurements.
